# MineCord

MineCord — це плагін для інтеграції Minecraft-сервера з Discord, що забезпечує синхронізацію чатів, управління сервером та автоматизацію рутинних завдань.

## Основні можливості

* **Двосторонній чат (Cross-chat):** Трансляція повідомлень між Minecraft та Discord. Використовує Webhooks для відображення реальних нікнеймів та аватарок гравців (за допомогою `mc-heads.net`).
* **Embed-сповіщення:** Системні події (вхід/вихід гравців, смерті, здобутки, статус сервера) форматуються як Embed-повідомлення в Discord.
* **Динамічний статус:** Бот автоматично оновлює статус у Discord, відображаючи поточну кількість гравців.
* **Система авторестартів:** Вбудований планувальник перезавантажень сервера:
  * Керування через Discord-команди (`/autorestart`).
  * Повідомлення в ігровий чат та на екран (Title) перед перезавантаженням.
  * Можливість вимкнути індивідуальні сповіщення командою `/togglerestart`.
* **Синхронізація акаунтів:** Можливість прив'язки ігрового акаунта до профілю Discord.
* **Режим технічних робіт:** Керування доступом до сервера (Whitelist) безпосередньо через Discord (`/maintenance`).
* **Віддалена консоль:** Спеціальний закритий канал у Discord для перегляду логів та виконання серверних команд.
* **Slash-команди:** Підтримка нативних команд Discord (`/online`, `/help`, `/restart` тощо).

## Встановлення

1. Завантажте `MineCord-1.0-SNAPSHOT-all.jar` з останньої успішної збірки (Actions).
2. Розмістіть файл у директорії `plugins/` вашого сервера.
3. Запустіть сервер для генерації конфігураційних файлів.
4. Налаштуйте файл `plugins/MineCord/config.yml` (вкажіть токен бота та ідентифікатори каналів).
5. Перезапустіть сервер для застосування змін.

## Вимоги до системи

* Ядро: Spigot, Paper, Purpur або їхні форки (сумісність з API 1.13 - 26.x)
* Java: 21 або новіша

## Безперервна інтеграція (CI/CD)

Проєкт підтримує автоматичну збірку через GitHub Actions. При оновленні головної гілки система автоматично компілює проєкт (Gradle shadowJar) та розгортає його на цільовому сервері за протоколом SFTP.
